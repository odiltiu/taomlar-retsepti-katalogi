# 🍲 Taomlar Retsepti Katalogi (Recipes App)

Ushbu loyiha **React** yordamida yaratilgan bo'lib, DummyJSON API orqali turli taomlar retseptlari, kerakli masalliqlar (ingredients) va tayyorlanish bo'yicha batafsil ko'rsatmalarni ko'rsatadi.

## 🚀 Texnologiyalar

- **React 19**
- **DummyJSON Recipes API**
- **Tailwind CSS**
- **Vite**

## 🌟 Imkoniyatlar

- 30 dan ortiq xalqaro taomlar ro'yxati
- Taom tayyorlanish vaqti, kaloriyasi va murakkablik darajasi
- Kerakli masalliqlar ro'yxati
- Qadam-baqadam pishirish bo'yicha qo'llanma

## 💻 Ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dev rejimida ishga tushirish
npm run dev

# Production uchun build
npm run build
```
